# fs-smart-utils
Проект представляет собой набор полезных утилит для работы с файлами. 
## 1. fs-accessor-service 
Cервис предоставляет API для прямого взаимодействия с файловой системой. Для запуска сервиса, ему необходимо предоставить доступ к postgresql.
### Запуск:
1. Убедиться, что на рабочей машине присутствует и запущен docker
2. Перейти в fs-smart-utils (cd fs-smart-utils)
3. Выполнить команду <b>docker compose up</b> и дождаться запуска контейнера postgresql.
4. Запустить сервис.
